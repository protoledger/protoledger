# Термостенд — набор организаторов и восстановленный протокол

`sample_protocol/` — набор организаторов хакатона без изменений (архив `sample_protocol.tar.zst`, sha256 `35730e2918ed8e64cad11692b0ab8f187823ab59fd86a668b497df63b1af763f`): записи обмена штатного клиента с моделью измерительного устройства, журнал действий и описание набора (`sample_protocol/README_RU.md`).

`interpretation.yaml` — описание протокола, восстановленное с помощью protoledger: подсказки по границам и изменчивости байтов, связи с журналом действий, затем проверка на корпусе. `expected/` — результат `protoledger apply` на каждой записи.

## Протокол

Заголовок 8 байт: сигнатура `A6 5C`, длина тела `u16` (старшим байтом вперёд), номер запроса `u16` (ответ повторяет номер), направление (0 — запрос, 1 — ответ), команда.

| Команда | Запрос | Ответ |
|---|---|---|
| `0x10` чтение настроек | пусто | статус, настройки |
| `0x20` изменение настроек | настройки | статус, настройки |
| `0x30` чтение измерений | число измерений `u8` | статус, число, измерения по 7 байт |
| другая | — | статус `1` (неподдерживаемая команда) |

Настройки: включены `u8`, период `u16` мс, порог `i16` в сотых долях °C, длина метки `u8`, метка в UTF-8. Измерение: время устройства `u32` мс, температура `i16` в сотых °C, тревога `u8`. Статус: 0 — ок, 1 — неподдерживаемая команда, 2 — некорректное тело, 3 — значение вне диапазона, 4 — измерения отключены.

Байтовые поля описаны как гипотезы с тестами по журналу действий; структурные — правилами.

## Повторить

Из корня репозитория, бинарник `protoledger` из сборки или образа:

```bash
protoledger apply --interpretation examples/thermostand/interpretation.yaml \
  --input examples/thermostand/sample_protocol/additional/04_new_observations.pcapng \
  --action-log examples/thermostand/sample_protocol/action_journal.csv \
  --mapping examples/thermostand/mapping.yaml
```

Все эталоны сразу: `bash examples/check.sh protoledger`.

Журнал описывает все записи набора: колонка `capture` в `mapping.yaml` (`source`) привязывает действие к своей записи, параметры и результат — JSON внутри ячейки.
