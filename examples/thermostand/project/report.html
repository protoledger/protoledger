Открытые вопросы

  • q-2: Есть ли у устройства команды кроме 0x10, 0x20 и 0x30? В записях другие коды встречаются только в контрольной отправке клиента, устройство отвечает статусом 1.

Закрытые вопросы:

  • q-1: Порог знаковый или беззнаковый? — Знаковый (i16): отрицательные пороги из журнала совпадают с байтами только при знаковом чтении.

Как воспроизвести

Нужен движок protoledger версии 0.1.0: статический бинарник для Linux, Windows или macOS либо установщик настольного приложения со страницы Releases репозитория github.com/protoledger/protoledger, или сборка из этого репозитория командой docker compose up --build. Сеть и другие зависимости не нужны.

Проект переносится копированием папки. Результаты перепроверяются командой (код возврата 0 — совпало, 1 — отличия):

protoledger verify <папка проекта>

Описание применяется к новым записям без проекта:

protoledger apply --interpretation <файл> --input <запись>
